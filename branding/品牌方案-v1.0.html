00一页结论

如果只看一页，看这一页。

推荐品牌名 SEREIA（读作 se-RAY-ah），葡萄牙语「美人鱼」。品牌信条 Salt & Steel，主标语 Made for salt water.

为什么是这个名字
6 个字母、两秒念对、有海域联想但不直白；造词感与参考站同频，却避开了「Ocean / Wave / Tide」这类 SEO 红海词。
它解决了什么问题
$58 起的价格带需要有「品牌感」支撑。一个能讲故事的词 + 一枚可缩到 16px 的标记，比打折更能撑住溢价。
它承担什么风险
葡语常用词，巴西可能有同名主体。必须先做 Class 14 商标检索，通过才定稿，不通过就走备选 B（MAREA）。

三个必须由你决定的点

#决策选项与我的建议
B1品牌名用哪个A. SEREIA（推荐）　B. MAREA　C. TIDEGLASS　D. 你自己另有想法
建议 A，商标检索不通过则退 B。

一句提醒：品牌方案里所有 LOGO 我都做成了矢量（SVG），可以无损放大到广告牌、也能缩到浏览器标签页。但字标部分目前用的是系统衬线字体渲染，正式上线前必须让设计师把字母转成曲线路径（转曲），否则换台电脑字距就会变。

01命名

先定标准，再筛候选，最后给推荐。顺序不能倒，否则就是在几十个「听起来不错」的词里凭感觉抓一个。

1.1 命名标准先立规则

跨境 DTC 饰品品牌的名字要同时过五关，任何一关不过都会在后期变成成本：

#标准具体要求不过关的后果
N1一次念对英语母语者看到拼写能读出来，听到读音能拼回来。不超过 3 个音节、不超过 8 个字母。客服每天纠正发音，口碑传播失效
N2可注册不是通用词、不是纯描述词；USPTO Class 14（珠宝）无近似在先商标。做起来被诉侵权，被迫改名＝品牌资产归零
N3域名可得.com 或「品牌 + jewelry」组合可得，价格在 $3,000 以内。只能挂 .shop，邮件进入垃圾箱概率上升
N4与品类有暗线与水、光、恒久、自然之一有关联，但不直白（不要 Ocean / Wave / Beach）。直白词 SEO 打不动，且显廉价
N5撑得住价格念出来要像 $58–$143 的东西，不能像 $9.9 的快时尚。价格带上移后转化崩掉

1.2 六个候选按 N1–N5 打分后保留

下表是我从 40 多个方向里筛出的 6 个。评分满分 5 分，总分 25。

SEREIA /seˈreɪ.ə/ · se-RAY-ah 推荐 24 / 25
含义与来源
葡萄牙语「美人鱼」。同源自古希腊 Seirḗn（塞壬），是「用歌声留住水手」的那一类存在。它不是直白的海洋词，而是一个有画面的角色。
为什么选它
6 个字母、两个音节、拼读零歧义；元音交替（e-e-i-a）念起来有潮汐起伏感；词形独特，商标冲突概率低于常见词；与「可戴着下海」的产品事实天然自洽。
风险：巴西有同名泳装/饰品主体，必须做检索。
MAREA /məˈreɪ.ə/ · mah-RAY-ah 备选 B 22 / 25
含义与来源
意大利语与西班牙语「潮汐」，源自拉丁语 mare（海）。
评价
极短、好念、含义正面。但 Marea 是菲亚特一款车型名，且时尚领域已有使用，.com 几乎必然被占。作为 SEREIA 检索不通过时的第一备选。
TIDEGLASS /ˈtaɪd.ɡlæs/ · TIDE-glas 备选 C 21 / 25
含义与来源
海玻璃：被海浪打磨几十年的碎玻璃，边缘变圆、表面起雾，但内部始终有光。
评价
这是我个人最喜欢的故事——它几乎就是「不褪色的不锈钢」的隐喻：时间只改变表面，不夺走本质。缺点是三个音节、9 个字母，且偏冷僻，需要额外解释成本。
NAIADE /naˈjɑːd/ · nah-YAHD 淘汰 18 / 25
含义与来源
法语「水仙女」，源自希腊神话中的 Naiad（掌管淡水泉源的宁芙）。
淘汰原因
拼写与读音对英语用户不友好（-ade 会被读成「奈阿德」）；法国有同名泳池设备品牌，品类氛围被污染。
EVERWAVE /ˈev.ər.weɪv/ · EH-ver-wave 淘汰 17 / 25
含义与来源
造词，ever（永远）+ wave（浪）。直译就是「永不停止的浪」。
淘汰原因
太直白，一眼看懂也就一眼忘掉；两个实词拼接在英文商标里属于弱显著性强组合，注册难度高；念起来像运动饮料。
SELKIE /ˈsel.ki/ · SEL-kee 淘汰 16 / 25
含义与来源
苏格兰与爱尔兰神话中的海豹精灵：白天是海豹，夜里脱下皮变成人。
淘汰原因
故事极好，但 Selkie 已是一个知名度较高的美国连衣裙品牌，品类相邻（都是女性服饰配件），冲突风险最高。忍痛放弃。

1.3 推荐：SEREIA

一句话说清它是什么：SEREIA 是一个「海边的女孩不需要摘下首饰」的品牌。

名字怎么用

场景写法说明
正式全称SEREIA全大写，永不加 s，永不用小写开头
口语／域名Sereia句中出现时首字母大写即可
带品类Sereia Jewelry仅用于域名、发票抬头、平台店铺名
中文内部叫法塞瑞亚（暂定）仅内部沟通与中文素材使用，不对外
错误写法Sereia's · SEREIA JEWELRY CO. · Sereia jewelry所有格、加后缀、混大小写都会稀释标记

品牌信条与标语

层级文案使用位置
信条（内部）Salt & Steel　盐与钢不对外做广告语，用于包装内页、吊牌背面、团队内部对齐
主标语（对外）Made for salt water.首页 Hero 副标、包装卡、邮件签名
支撑句316L steel. PVD colour. Colour guaranteed for life.商品页卖点条、Meta description
情绪句Swim in it. Sleep in it. Forget it's there.社媒文案、场景图配文
为什么主标语不是「Waterproof Jewelry」：防水是品类的基础门槛，所有同行都在说，说了等于没说；Made for salt water 把场景推到极限（海水是最腐蚀的日常环境），一句话同时完成了「差异化」和「可信度」两件事，而且它是个短句，能印在 3cm 宽的包装卡上。

1.4 商标与域名尽调这是定稿前的硬门槛

我不能替你做法律检索，但可以把检索路径和判定标准写清楚。以下动作建议在三天内并行完成，任何一项红灯就退到备选 B。

#动作怎么查 / 判定标准
C1USPTO 商标检索在 tmsearch.uspto.gov 搜 SEREIA，限定 Class 14（珠宝）与 Class 35（零售服务）。判定：无「相同或高度近似 + 同类别 + 存活状态」的记录即通过。
C2EUIPO / UKIPO 检索英国是目标市场，需单独查 UKIPO；欧盟可一并查。判定标准同 C1。
C3域名优先 sereia.com；退而求其次 sereiajewelry.com、wearsereia.com、sereia.co。判定：能买断，不要租。
C4社媒 handleInstagram / TikTok / Pinterest 三处 @sereia 或 @sereiajewelry 至少一处可用，且三处名称一致。Pinterest 对饰品引流权重高，别漏。
C5Google 结果污染搜 SEREIA，看首页是否被其他行业大品牌占据。若前三页全是别家，说明这个词已被占用为品牌符号，慎用。
如果 C1 或 C2 不通过：不要抱有「先做起来再说」的侥幸。饰品类目被投诉侵权的典型后果是平台店被封 + 独立站支付通道被冻结，损失远大于改名成本。退备选 B（MAREA），我会在 24 小时内出对应 LOGO 与文案替换。

02品牌核心

名字是壳，这一段是核。所有文案、图片、页面顺序最终都要服从这一段。

2.1 定位陈述

对于 22–38 岁、住在沿海城市、每周至少下水一次的北美女性，
她们 已经放弃买便宜饰品（戴两周就发黑），又不愿意为 14K 金支付 $300+，
SEREIA 是 一个只用 316L 不锈钢 + PVD 镀层、并承诺「颜色终身保证」的饰品品牌，
因为 我们相信饰品应该在游泳、洗澡、睡觉时都不用摘下，
而不是 像快时尚饰品那样，需要被小心翼翼地供起来。

三个「不」

  • 不做「防水」作为卖点——防水是入场券。我们说「颜色终身保证」，这是承诺级别，不是参数级别。
  • 不做「平替」叙事——不说「14K 金的平价替代」。我们是另一种材质路线，不是廉价版本。
  • 不做「少女感」——不用粉色、不用爱心、不用「cute」。波希米亚是成年女性的自由感，不是可爱。

2.3 品牌承诺与三层证据

承诺不能只有一句话，必须有可验证的证据链，否则就是空话。我们把「颜色终身保证」拆成三层：

层级内容怎么让人信
事实层316L 外科手术级不锈钢 + PVD 真空镀层商品页列出材质参数（厚度、镀层微米数）；不说「高级不锈钢」这种模糊词
行为层终身免费换新一次，运费各半，旧件不退回把条款写在商品页价格下方（不是埋在 FAQ）；换新入口在订单查询页直接可见
证据层真实用户的长期佩戴记录评价里强制显示「购买距今 N 个月」；每月发一条「戴了 X 个月后」的对比图
财务上它站得住吗：按 FRD v1.1 的模型，计提营收 2% 作颜色保证准备金。年销 2 万件、换新率 5% 时成本约占营收 1.6%，可覆盖；若换新率升到 15%，成本升至 4.8%，毛利被吃掉近一半。所以这条承诺的前提是 PVD 工艺稳定——入库抽检与留样必须做，否则承诺会从资产变成负债。

2.4 差异坐标

横轴是价格，纵轴是「材质路线」——这是这个品类真正的分水岭，比风格轴更能解释用户为什么买。

品牌价格带材质路线它占据的心智
SEREIA$58–$143不锈钢 + PVD，终身颜色保证海水里的日常首饰——不用摘的那一条
Atolea$58–$143不锈钢 + PVD同样的材质路线，但讲的是「欧洲海边度假」
Pura Vida$20–$60合金 + 编织，公益联名便宜、有意义、可送人，但不耐用
Mejuri$80–$40014K 金 / 纯银轻奢日常，可传承
Shein / Temu 白牌$3–$15铜 + 电镀便宜、快、戴两次就黑

空白位在哪：Atolea 之下无人认真做、Mejuri 之上我们够不着。我们和 Atolea 在同一格，所以差异必须落在「承诺强度」与「叙事角度」上，而不是价格。

2.5 语气与文案

这样说

  • 具体、可验证：「316L steel, 0.8 micron PVD」
  • 第一人称、克制：「We'd rather you keep it than return it.」
  • 用动作替代形容词：「Swim in it.」而不是「It's waterproof!」
  • 允许不完美：「It will pick up fine scratches. That's steel being honest.」
  • 句子短。一行不超过 12 个词。

不这样说

  • 堆感叹号：「Gorgeous!!! You'll LOVE it!!!」
  • 无证据的绝对化：「永远不褪色、永不变形、永不磨损」
  • 制造焦虑：「再不买就没货了（其实库存 300）」
  • 品类黑话：「ins风」「高级感」「氛围感」
  • 少女化称呼：「小仙女」「宝宝们」
一条可执行的检验方法：写完任何一段文案，问自己「这句话能不能被同行原样抄走？」如果答案是「能」，就重写。能被抄走的文案不是品牌资产。

3.9 摄影风格

维度规范
光线硬光、侧逆光为主，允许真实阴影。不做柔光箱式的均质平光——那会让不锈钢看起来像塑料。
背景三类：① 纯色暖白/沙色（商品主图）；② 真实场景（皮肤、亚麻、湿沙、海水）；③ 硬质石材（做质感对比）。不用渐变背景。
人物只拍局部：手、锁骨、耳、脚踝、湿发。不拍正脸——正脸会把品牌绑定到某个人，且跨种族市场适配性差。
色调低饱和、暖偏冷白平衡。整体在 HSL 上压 8–12% 饱和度。禁止高对比滤镜和胶片模拟。
构图商品图统一 4:5，主体占画面 55–65%，留白不对称。场景图允许 3:2 与 1:1。
后期只做曝光、白平衡、污点修复。不磨皮、不去除金属划痕——划痕是「钢的诚实」。
