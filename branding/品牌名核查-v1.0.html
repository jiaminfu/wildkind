WK-BR-002 · 品牌名可用性核查

六个候选，只有一个
商标和域名同时干净

核查对象：SEREIA、MAREA、TIDEGLASS、NAIADE、EVERWAVE、SELKIE。判定标准是「能不能真的用这个名字做生意」，不是「听起来好不好听」。

核查日期：2026-11-13 数据源：USPTO 公开商标库 · IANA RDAP 全球域名注册库 版本：v1.0

0. 一句话结论

TIDEGLASS —— 商标空白，三个域名可买，故事与产品自洽

唯一一个「USPTO 珠宝类 零记录」且「tideglassjewelry.com / tideglass.shop / tideglass.store 全部可注册」的候选。海玻璃本身就是「被海浪打磨几十年仍透光」的东西——正好是 316L + PVD「不褪色」的实体隐喻。
代价：9 个字母、3 个音节，冷僻词，需要一句解释成本。

SEREIA 必须暂停。USPTO 里已有一件 Class 14（珠宝） 的「SEREIA OFFICIAL」在审申请，商品描述逐条写着 Earrings; Jewelry; Bracelets; Jewelry rings; Necklaces —— 与你完全同品类。另有 6 件 2026 年提交的「SEREIA」化妆品申请，说明这个词正在被大量抢注。继续用，等于把品牌建在别人的地盘上。

2. 逐个候选的证据

TIDEGLASS 建议采用 商标干净
商标核查 以 tideglass 与 tide glass 两种拼写在 USPTO 公开库检索，没有任何同名记录。相邻词（TIDELINE、TIDEGRAPH、TIDE TIMER）全部是潮汐钟表/航海图类，与珠宝不构成混淆。这是六个候选里唯一「完全没有历史包袱」的词。 域名核查 tideglass.com 于 2025-11-16 被 Automattic（WordPress 母公司）注册，属防御性持有可能，买断需议价。tideglassjewelry.com、tideglass.shop、tideglass.store 三个均未注册，可立即按原价拿下。 品牌判断 海玻璃是被海水磨了几十年、边缘变圆、表面起雾，但内部始终有光的东西。用它做「不褪色的钢」，比任何海洋词都更准确——因为它在讲同一件事：时间只改变表面，不改本质。
NAIADE 域名最优 商标干净
商标核查 无 Class 14 记录。现存记录为：香水（1988）、家纺（2024-09）、泳装 NAIADE THE LABEL（2025-05）。泳装与饰品同属女性穿戴，属「相邻但不冲突」。 域名核查 naiade.com（2001）、naiade.shop、naiade.store 已被占，但 naiadejewelry.com、getnaiade.com、naiadestudio.com 三个 .com 全部可用——六个候选里域名可操作空间最大。 为什么不推荐 读音是硬伤。-ade 在英语里会被读成「奈阿德」，正确读音 /naˈjɑːd/ 需要额外教学。一个需要教用户怎么念的品牌名，每投一次广告都在漏钱。
EVERWAVE 可用但平庸
商标核查 无 Class 14。现存：护发液（1978）、旗杆（2013）、净水滤芯（2017）、数字艺术品市场（2022）。类别都不冲突。 域名核查 everwave.com 2002 年被占；everwavejewelry.com、everwave.shop、everwave.store 可用。 判断 ever + wave 是「两个实词硬拼」，在英文商标法里属于弱显著性强组合，注册能过但保护范围窄——别人加个前缀做 EVERWAVE CO. 你拦不住。另外它念起来像运动饮料或冲浪服，不像饰品。
SELKIE 认知已被占
商标核查 Class 14 无记录，但 Class 25 有「SELKIE」由 BIG HEART USA LLC 持有（2016 年注册，2024 年又加注一批连衣裙、泳装、沙滩罩衫）。Selkie 在美国是一个有知名度的连衣裙品牌，社媒上有稳定声量。 域名核查 selkie.com（1998）、selkiejewelry.com（2015）、selkie.shop 全被占；仅 selkie.store、wearselkie.com 可用。 判断 法律上你或许能在珠宝类注册成功，但营销上你是在给别人的品牌做免费广告——搜 Selkie 的人找的是裙子。这就是「品类污染」，商标过了也没用。
SEREIA 高风险 · 建议放弃
致命证据 USPTO 序列号 98755473「SEREIA OFFICIAL」，申请人 SEREIA OFFICIAL LLC，2024-09-17 提交，Class 14，商品描述含 Earrings; Jewelry; Bracelets; Jewellery chains; Jewelry rings; Necklaces; Pendants as jewelry。当前状态 630（新申请，尚未分配给审查员）——仍属存活申请，会构成实质障碍。 拥挤度 另有 5 件 2026 年提交的「SEREIA」化妆品类申请（SEREIA、SEREIA BEAUTY、SEREIA K-LIFT ×2），申请人多为中国主体。这个词正在被批量抢注，即使 Class 14 侥幸绕过，品牌辨识度也会被稀释。 域名核查 sereia.com 2002 年即被注册（GoDaddy 代管，2027 到期），属长期持有，买断价预计四位数美元。sereiajewelry.com、wearsereia.com 可用。 如果要坚持用 必须做两件事：① 委托商标代理人做 USPTO + EUIPO + UKIPO 三地 Class 14 正式检索报告；② 评估「SEREIA OFFICIAL」的异议/撤销可行性。两项成本通常在 $1,500–3,000 之间，且不保证通过。
MAREA 出局
致命证据 USPTO 序列号 99009231「MAREA」，申请人 Pure Joy Home LLC，2025-01-17 提交，商品描述就一个词：Jewelry。同一持有人 2023 年还注册了 MAREA 连衣裙、帽子、沙滩罩衫——这是一个完整的海边女装品牌矩阵。 域名核查 这是六个候选里最糟的：marea.com（1997）、mareajewelry.com（2024）、wearmarea.com（2026-09）、marea.shop、marea.store 全部被占。连退路都没留。 判断 商标与域名双杀。无论从哪个角度看都不该选。

5. 本次核查的边界

必须说清楚，避免把这份报告当成法律意见：

  • 覆盖 USPTO（美国） 公开商标库与 IANA RDAP（全球域名）。美国是你的主力市场，这里是主战场。
  • 未覆盖 EUIPO（欧盟）、UKIPO（英国）、CIPO（加拿大）的官方注册库——这三家不提供免费公开 API，需付费检索工具或委托代理。
  • 商标「检索干净」不等于「一定注册成功」，审查员仍可能基于近似判定驳回；域名「可注册」不等于「适合长期持有」，需确认不是溢价域名。
  • 建议在正式申请前，把这份表交给商标代理人做一次正式检索（Clearance Search），费用通常在 $300–600，是这笔生意里最便宜的保险。
