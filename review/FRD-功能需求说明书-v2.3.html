1项目概述

1.1 背景

面向北美市场的不锈钢饰品 DTC 独立站。产品为 316L 不锈钢 + PVD 镀层，主打"低敏、可长期佩戴、可碰水、终身不掉色"，价格带 $58–$143（对齐参考站，其中 14K 镀金与珍珠款落在 $120 以上），首批 100 款 SKU。渠道策略是用主题化集合替代导航深度：一件商品同时挂进品类、题材、送礼对象、榜单等多个集合，让用户从任意入口都能落到商品。

1.2 本轮目标

  1. 把参考站（Atolea Jewelry）的信息架构、页面构成、交互模式完整还原，作为我们自己的基线；凡是主动偏离的地方必须显式标注理由，不与复刻项混写。
  2. 明确前台与后台的功能边界、字段、状态、业务规则，作为开发与验收的唯一依据。
  3. 用线框原型把结构先确定下来，避免在视觉与代码上返工。

1.3 阅读方式

每条需求有唯一编号（FR-S-xxx 前台 / FR-A-xxx 后台），带优先级与验收标准。优先级标注：🔴 高（MVP 必须）/ 🟡 中（首版应有）/ 🟢 低（可后置）。凡标注"待确认"的条目，需你确认后才进入设计。

来源标注规则（v1.1 新增）：需求描述末尾的 复刻 表示参考站确有该形态、我们按原样实现；增强 表示参考站没有或未确认、我建议增加；偏离 表示参考站有但我们主动不做，需在第 12 节记录理由。这样你可以直接判断哪些能砍。

2范围边界

2.1 本期包含

  • 前台：首页、集合页、商品详情、搜索、购物车、结算、订单完成、订单查询、评价提交、内容页、404，以及账户中心（登录 / 注册 / 概览 / 订单 / 地址簿 / 心愿单 / 设置，见 5.9）。
  • 后台：登录、概览、订单、商品、库存、集合、客户、内容、营销中心、评价管理、定制需求单、设置。
  • 交易：Stripe 支付、订单邮件、库存扣减、退款登记。
  • 营销：优惠券、限时补贴（自动折扣）、满额赠品、免邮门槛；均由后台配置，前台动态呈现。
  • 售后：终身颜色保证换新（真承诺）、30 天无理由退换、评价审核。

2.2 本期明确不做

  • 账户体系做，访客下单也保留——二者并存：不注册可直接下单，注册后订单自动归入账户。v2.0 修订 理由见 5.9 开头：账户支撑复购与订单归属，但不该成为成交流程的门槛。
  • 第三方社交登录（Google / Apple / Facebook SSO）不做，首版仅邮箱 + 密码。偏离
  • 多语言（首版仅英文）。多币种同样不做——参考站按地区自动切币（我抓取其商品页显示 €51,95、集合页显示 $75），我们主动简化为全站 USD，属明确偏离。 偏离
  • 集合三轴（风格 / 材质 / 宝石）不做，仅保留品类轴 + 题材轴 + 送礼对象轴。理由：三轴会让 mega menu 从两层变三层、导航显著变深，与"用集合替代深度"的建站策略冲突；长尾关键词改由落地页与 SEO 文案承接。偏离
  • 会员积分、拼团、直播、社区、分销裂变。
  • 第三方评价插件（Trustpilot / Judge.me / Loox）——改为自建评价系统，后台人工审核。
  • 自建仓配系统（对接第三方海外仓，仅做发货回填）。
  • 站内 AI 客服（首版用邮件 + FAQ）。
关于"结构完全一样"：参考站的一级导航 11 项、mega menu 分组、商品卡信息密度、集合页筛选维度，我们都按原结构复刻；但文案、图片、配色会替换成我们自己的品牌资产，不涉及版权素材。v1.1 起，每条需求都标了来源（复刻 / 增强 / 偏离），不再混写。

12.5 仍未解决、需要你注意的两处

1. 价格带上移的经营风险。$58 起意味着要和 Atolea、Pura Vida 正面拼品牌而不是拼价格。参考站能卖 $58 是因为它有 7M+ 件销量、1.6M+ 客户、4.7 分评分做背书。我们首版没有这些，前 3 个月大概率要靠 Meta 广告 + 红人内容换信任，CAC 会偏高。价格带本身没错，但不能假设"标价上去就卖得动"，推广预算和测款节奏要跟上。

2. 终身颜色保证的兑现成本。按年换新率 5% 估，若年销 2 万件、客单价 $88，则年换新 1000 件，单件成本约 $28（货品 18 + 关税 5.58 + 头程 0.99 + 双向运费约 $3.5），合计约 $2.8 万，占营收 1.6%——2% 准备金能覆盖。但若供应链批次不稳导致换新率到 15%，成本会翻到 4.8%、毛利被打掉一半。所以这条承诺的前提是 PVD 工艺稳定，首版必须在入库环节抽检并留样，否则承诺会变成负债。
