1项目概述

1.1 背景

面向北美市场的不锈钢饰品 DTC 独立站。产品为 316L 不锈钢 + PVD 镀层，主打"低敏、可长期佩戴、可碰水"，价格带 $35–$85，首批 100 款 SKU。渠道策略是用主题化集合替代导航深度：一件商品同时挂进品类、题材、送礼对象、榜单等多个集合，让用户从任意入口都能落到商品。

1.2 本轮目标

  1. 把参考站（Atolea Jewelry）的信息架构、页面构成、交互模式完整还原，作为我们自己的基线。
  2. 明确前台与后台的功能边界、字段、状态、业务规则，作为开发与验收的唯一依据。
  3. 用线框原型把结构先确定下来，避免在视觉与代码上返工。

1.3 阅读方式

每条需求有唯一编号（FR-S-xxx 前台 / FR-A-xxx 后台），带优先级与验收标准。优先级标注：🔴 高（MVP 必须）/ 🟡 中（首版应有）/ 🟢 低（可后置）。凡标注"待确认"的条目，需你确认后才进入设计。

2范围边界

2.1 本期包含

  • 前台：首页、集合页、商品详情、搜索、购物车、结算、订单完成、订单查询、内容页、404。
  • 后台：登录、概览、订单、商品、库存、集合、客户、内容、设置。
  • 交易：Stripe 支付、订单邮件、库存扣减、退款登记。

2.2 本期明确不做

  • 用户注册与登录体系（首版仅访客下单，订单号 + 邮箱查询）。待确认
  • 多语言、多币种（首版仅英文 + USD）。待确认
  • 会员积分、优惠券裂变、拼团、直播、社区。
  • 自建仓配系统（对接第三方海外仓，仅做发货回填）。
  • 站内 AI 客服（首版用邮件 + FAQ）。
关于"结构完全一样"：参考站的一级导航 11 项、mega menu 分组、商品卡信息密度、集合页筛选维度，我们都按原结构复刻；但文案、图片、配色会替换成我们自己的品牌资产，不涉及版权素材。

8订单状态机

待支付 pending→已支付 paid→配货中 fulfilling→已发货 fulfilled→已完成 completed
待支付→已取消 cancelled（超时 / 用户取消）
已支付 / 已发货→退款中 refunding→已退款 refunded
状态触发可执行操作客户可见
pending创建订单未支付取消待支付
paid支付回调成功配货、取消并退款已支付
fulfilling后台开始配货填运单发货备货中

10验收清单

  • 11 项一级导航在 1440 / 1024 / 390 三档下均正确呈现，无换行、无横向滚动。
  • 从首页进入某题材集合 → 筛选金属色 → 进商品 → 选变体 → 加购 → 结算 → 支付成功，全链路无阻断。
  • 下单后后台订单列表出现新订单，库存相应扣减，金额与前台一致。
  • 用订单号 + 邮箱可查到刚下的订单；邮箱错误时查不到。
  • 后台改价、改库存、改首页文案，前台刷新后立即生效。
  • 连续点击下单按钮 5 次，只产生 1 笔订单。
  • 移动端 390px 全站无横向溢出。
