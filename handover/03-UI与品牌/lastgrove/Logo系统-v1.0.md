## 2 图形释义 · A · The Pendant

几何全部是 path / circle，不依赖字体。`viewBox="0 0 120 120"`。

| 元素 | 参数 | 含义 |
|---|---|---|
| 圆环 | 中心 (60,60)，r=48，线宽 5，顶部留约 16° 缺口 | 项链圈、戒指、发圈的共同形状；**几乎闭合＝戴上就不必摘** |
| 搭扣点 | 圆心 (60, 12.47)，r=4.5，Clay 实心 | 把缺口「扣上」的那一下；也是整套视觉里唯一的暖色，面积 < 5% |
| 小树 | 主干 `y 103→64`，两枝自 `y 82` 斜出 | `grove`；树长在环里，像吊坠上刻的图案 |

**三层意思**：① 一枚吊坠（品类）② 一个不用摘的环（产品承诺）③ 一片慢慢长的林子（名字）。
**刻意不做**：地球、叶片、水滴、手、星星、无限符号 —— 避免读成环保组织或灵性品牌。

### 2.1 三个方向对比（见 `lastgrove-options.png`）

| 方向 | 图形 | 优点 | 为什么没选为主推 |
|---|---|---|---|
| **A · The Pendant** | 环 + 树 + 搭扣点 | 同时扣住品类、产品承诺与名字；16px 可辨；能单独做压印 | — |
| B · The Grove | 三棵树冠 + 地平线 | 「一片林子」最直白，友好、好懂 | 太像有机食品 / 园艺 / 童装品牌，饰品感弱 |
| C · The Rings | 三道同心年轮 + 一点 | 最抽象、最高级，讲「经年」 | 缩到 16px 会糊成靶心，且与大量腕表/音响 logo 撞型 |

> B、C 保留在 `lastgrove-options.svg` / `.png` 里，若你更中意可以直接说，改 `gen-lastgrove-logo.js` 里的 `directionB()` / `directionC()` 提为主标即可。

## 4 色彩系统（沿用既有色板，不改色值）

品牌一致性优先：色值与 `品牌最终方案-Weftvale-v1.0.md` 第 5.1 节完全一致，只把 Verdigris 在本品牌语境里称作 **Grove Green**。

| 角色 | 色值 | 在 logo 里的用法 |
|---|---|---|
| **Ink** | `#1B2B2E` | 字标、单色版、深底 |
| **Mist** | `#EDF1F0` | 页面底、反白版图形与字 |
| **Grove Green** | `#4A7C6F` | 圆环、小树（主行动色） |
| **Sand** | `#C9B79C` | 次级底、分隔；不进 logo |
| **Clay** | `#A85F4B` | 仅搭扣点，面积 < 5% |

**对比度**：Ink on Mist 反差充足，正文级可读；Grove Green on Mist 用于图形元素（logo 属图形，门槛低于正文）；Clay 点面积过小，不承担对比度责任。精确比值请在上线前用对比度工具复核一次。

## 5 组合规范

| 项 | 规定 |
|---|---|
| 图形与字标间距 | **0.4 × mark 宽**（120 单位制下 = 48 单位）。横版 `primary` 从 x=178 起排字标，已按此实现 |
| 四周安全留白 | ≥ 0.4 × mark 高（48 单位），留白内不放任何文字、图标、边框 |
| 竖版间距 | mark 底到字标顶 ≈ 46 单位，同按 0.4× 控制 |
| 数字最小尺寸 | 横版宽 ≥ 180px；单独 mark ≥ 24px；**< 24px 一律用 favicon 简化版** |
| 印刷最小尺寸 | 横版宽 ≥ 35mm；单独压印 mark ≥ 12mm（再小树的两枝会并掉） |
| 字标基线 | 与 mark 视觉中心对齐，不做上下错位 |
| Tagline | `Grows on you.` **不进 logo**，作为独立元素另排，见 `品牌故事与文案-v1.0.md` |

## 6 字体与转曲（🔴 上线前必做）

SVG 里字标是 `<text>`，字体栈为：

```
'Cormorant Garamond', Georgia, 'Times New Roman', serif
```

- **推荐**：Cormorant Garamond（SIL OFL，可免费商用），自托管 woff2；或直接用它出图。
- **当前预览图**是在没装该字体的环境里渲染的，实际显示为 **Georgia** —— 观感稳重可用，但这属于 fallback，不是定稿字形。
- **必须转曲**：在 Figma / Illustrator 里对字标执行 Create Outlines，导出纯 path SVG，再替换 `lastgrove-primary.svg` / `stacked.svg` / `reverse.svg` / `sheet.svg` 里的 `<text>`。否则不同设备、不同浏览器会显示成不同字体，字标宽度一变，0.4× 间距规范就失效。
- 图形 mark 不含任何文字，**无需转曲**，可直接使用。

正文/UI 字体仍为 Inter（SIL OFL），数字用 tabular。

## 7 变体使用规则

| 场景 | 用哪个 |
|---|---|
| 白/浅底页头、文档、发票 | `primary` |
| 深色 hero、深色页脚、视频 | `reverse` |
| 社媒头像、圆形裁切 | `mark`（Mist 底） |
| 包装压印、激光刻、单色印刷 | `mark-mono` |
| 浏览器标签 16px / App 图标 | `favicon` |
| 竖版吊牌、盒子顶面 | `stacked` |
| 复杂照片背景 | 先用 Ink 或 Mist 纯色块垫底，再放对应变体；不要把彩色版直接压在照片上 |

## 8 禁用示例（Do's and Don'ts）

| 不要 | 原因 |
|---|---|
| 拉伸、压扁、倾斜、加透视 | 圆环一变形，整个识别就没了 |
| 旋转 mark（尤其别倒过来） | 树会朝下，语义反转 |
| 改色：全绿、全黑、去掉 Clay 点 | Clay 是唯一暖色记忆点；单色版是唯一例外 |
| 加阴影、渐变、描边、立体、发光 | 与克制的品牌声音冲突 |
| 把树单独拎出来用 | 脱离环就丢了「吊坠/不摘」两层意思 |
| `LASTGROVE` 全大写 / `LastGroVe` 混排 | 字标定稿为全小写 |
| 把 tagline 塞进 logo 或每页页脚重复 | 双关会被磨平，见文案文档第 6 节 |
| 在 logo 旁再放一个装饰性齿轮/设置图标 | 会破坏 DTC 站面的调性，后台入口应低调处理 |

## 9 商标图样与保护（建议动作）

| # | 动作 | 说明 |
|---|---|---|
| 1 | 图形 mark 单独申请 | 与文字标分开递交，保护范围更宽；美国 Class **014**（珠宝）+ **026**（发饰/发夹）+ **025**（帽子，提前占位） |
| 2 | 字标单独申请 | 转曲后为标准字标图样；同时申请 `LASTGROVE` 文字商标 |
| 3 | 组合标另递交一份 | 用于实际使用场景取证 |
| 4 | 保留创作证据 | 本文件、`gen-lastgrove-logo.js`、生成时间，作为独立创作留档 |
| 5 | 上线前付费 clearance | 与品牌名一起做，见 `品牌命名方案-v4.0.md` 第 7.2 节 |

> 本文件不是法律意见；商标可注册性以 USPTO / 代理机构的 clearance report 为准。
