**v4.0 相对 v3.0 的策略调整**

| Weftvale 的问题 | 本轮规避方式 |
|---|---|
| `weft` 是纺织术语，美国人不懂 | 核心词只用美式日常词，第一次就能念对 |
| `/ftv/` 三连辅音，念快了黏 | 拒绝三连辅音；≤3 音节；元音或响音收尾 |
| `-vale / -moor / -heath / -wold` 英伦奇幻味 | 换美式地名后缀 `-grove / -field / -glen / -haven / -brook / -ridge / -cove` |
| 中文地域故事对美国客户距离远 | 语义母题回到产品本身：持久、日常佩戴、随身小物 |
| 用户后续要卖帽子/发圈/挂件/发夹 | 品牌名不得含材质词、品类词；任意性商标优先 |

## 2 需求与验收标准

| 编号 | 需求 | 优先级 | 验收标准 |
|---|---|---|---|
| BR-4-01 | 好念，美国人第一次读对 | 🔴 高 | 无三连辅音；≤3 音节；核心词为美式日常词 |
| BR-4-02 | 不锁材质 | 🔴 高 | 名字不含 `steel / gold / silver / tide / glass / brine` 等材质或介质词（作为品牌名） |

| BR-4-07 | 可延展视觉与文案 | 🟢 低 | 能写出定位句、tagline、可讲的品牌故事 |

## 3 实测数据（2026-11-15，`tools/domain-check.js`）

| 批次 | 方向 | 查询 | 可注册 | 已注册 | 异常 |
|---|---|---|---|---|---|
| 第一批 | 美式地名 + 恒久/随身/水汗语义 | 44 | 4 | 39 | 1 |
| 第二批 | 冷门词根 + 缝纫配件/自然语义 | 85 | 17 | 66 | 2 |
| 第三批 | 高价值词根扩后缀 + 异常重查 | 73 | 26 | 47 | 0 |
| **合计** | | **202** | **47**（去重后 **46**） | **152** | **3** |

**结论：命中率 23%，明显低于 v3.0 的 46%。** 原因是本轮刻意用了美国人熟悉的美式地名词根（`-field / -brook / -haven / -ridge`），这些组合被 DTC 品牌注册得比古英语地貌词狠得多。想同时拿到「好念」和「`.com` 在手」，只能用**日常核心词 + 稍冷门后缀**。

异常项 `knotridge.com` / `strandhaven.com` / `larkbrook.com` 已重查，均判定为已注册，不列入可用清单。

`.shop` 查询曾出现 `RATE_LIMIT`，已逐批复查完成；`.co` / `.co.uk` 无公共 RDAP 端点，需到注册商人工查询（客户以美国为主，非必需）。

## 5 推荐梯队

### 🥇 首选 · LASTGROVE

| 项 | 内容 |
|---|---|
| 域名 | `lastgrove.com` ✓　`lastgrove.shop` ✓　`lastgrove.store` ✓ |
| 读音 | /ˈlæst ɡroʊv/，两拍，无辅音簇，美国人一次念对 |
| 语义 | `last` = 经得住、持久；`grove` = 小树林 |
| 定位句 | Made to last. Worn every day. |
| Tagline | **Made to last. Worn every day.**（副：No plating. Nothing to fade.） |
| 扩品类 | 帽子、发圈、挂件、发夹都能讲 "made to last"，名字里没有材质词、没有品类词 |
| 故事钩子 | 316L 本体不褪色、洗澡游泳不用摘 —— 名字本身就是产品承诺，不用另编传说 |
| 风险 | 🟡 `last` 是通用描述性词，单独保护力弱；组合词可注册，但需配图形字标，并在 Class 014/026/025 查 `LAST` 系在先权利（Last.fm 在 Class 041，不同类） |
