# 品牌命名方案 v3.0

*文档编号* TG-BR-002　　 *版本* v3.0（品类扩展 + 域名实测）　　 *日期* 2026-11-15

**本文件替代 `品牌方案-v2.1` 的命名章节。** v2.1 的 TIDEGLASS 已不成立，原因见第 1 节。v2.1 关于品牌故事、视觉、文案的部分仍然有效，仅名字需换。

## 1 为什么必须换名：v2.1 的核心假设已失效

v2.1 的判断是「TIDEGLASS 是六个候选里唯一商标、域名、含义三项全过的」。这个结论现在不成立：

```
tideglass.com          已注册（2025 年，Automattic Inc. — WordPress 母公司）
tideglassjewelry.com   可注册
tideglassstudio.com    可注册
```

`.com` 被 Automattic 拿走，意味着你只能退到 `tideglassjewelry.com`。而这个后缀**把品类锁死在珠宝上**——你接下来要卖帽子、发圈、发夹、挂件，域名里带 `jewelry` 是自我设限，客户看到网址就知道你"只卖家饰品"。

再加上 SEREIA 的前车之鉴（USPTO 98755473，Class 14 在先申请），换名不是审美偏好，是三个硬条件同时过期。

### 1.1 新的四条标准

v2.1 的三条（商标可用、域名可买、含义能承载产品事实）保留，**新增第四条**：

| # | 标准 | 这一轮怎么执行 |
|---|---|---|
| 1 | 域名可注册 | 250+ 候选逐个走 RDAP 实测，不含猜的 |
| 2 | 商标可注册 | 先排查已被占的核心词，再谈组合 |
| 3 | 含义能承载故事 | 优先能接「新余羽衣传说」的意象 |
| 4 | **能延展到非饰品** | 不能是 `-jewelry`、`-beads` 这类锁死品类的词 |

## 2 三个必须先接受的事实（都是实测数据，不是判断）

### 2.1 短 .com 已经不存在了

| 测试批次 | 样本 | 可注册 | 命中率 |
|---|---|---|---|
| 4–6 字母可发音词（pluma / wisp / vela / adornly …） | 20 | **0** | **0%** |
| 7–9 字母造词（plumara / solenna / adornova / zephyra …） | 20 | **0** | **0%** |
| 双词组合（weftvale / faylake / baoshimoor …） | 218 | 100 | **46%** |

**结论：想要 4–6 字母的 `.com`，只有三条路——买二手域名（$800–5,000）、换后缀（见第 5 节，`.shop` 上短词大片空着）、或者接受 8 字母以上的组合词。** 这不是我词穷，是 .com 池子在 2000 年前后被系统扫空，2025–2026 年还有 Atom.com 这类平台在批量囤货（`adornette.com` 就是 2026 年新注册的）。

### 2.2 组合词 .com 是唯一稳定路径，而且有公式

实测下来最稳的结构是 **`[核心词] + [地貌词]`**：

```
后缀命中率（同一批核心词下）：moor > vale / heath / wold / grove > meadow / drift / hill
```

这就是为什么下面第一批里 `-moor` 出现得最多——不是我偏爱，是它空位最多。你要是喜欢别的结尾，`-vale`、`-heath`、`-wold`、`-grove`、`-meadow`、`-drift` 我都验证过有可用组合，可以按核心词自由替换。

### 2.3 商标雷区：Class 14 已被中国卖家大量布局

这一轮实测到的在先商标，**四条都是硬证据**，不是推测：

| 核心词 | 证据 | 结论 |
|---|---|---|
| **PLUME** | CHANEL 在台湾持有 `PLUME`（注册号 01583725，Class 014 含项链、手镯、耳环、坠子）；DJECO 于 2025-05 向 USPTO 申请 `PLUME`（79427916），**Class 014 珠宝 + Class 026 发夹、发圈、发带、爪夹全在内** | 高危，`plumeX` 系全部避开 |
| **ADORN** | USPTO `A ADORN` 已注册（#6247344，Class 014，2021 年起有效）；台湾 `ADORN & HYG`（02401800，Class 014，有效至 2034） | 裸用高危，组合词可但需律师复核 |
| **PINION** | 英国 Pinion Watches（2013 年创立，£690–4,950），Class 014 同时覆盖珠宝与钟表 | 中高危 |
| **EGRET** | `EGRET FOREST` 已于 2025-04-15 在 USPTO 注册（#7763799，Class 014 覆盖手链、项链、戒指），申请人是**山东蓝翼宇** | 中高危，`egret + 自然词` 同模式 |

## 4 第二批｜33 个（新余渝水文化挖掘）

### 4.0 我挖到的素材：新余最值钱的东西是「羽衣」

这一节先说清素材来源，否则名字看着像乱拼。

**核心发现：新余是中国「羽衣仙女」传说的最早文字发祥地。**

东晋干宝《搜神记·毛衣女》记载：「豫章新喻县男子，见田中有六七女，皆衣毛衣……得其一女所解毛衣，取藏之。」豫章新喻就是今天的新余。这是七仙女下凡故事**现存最早的文本**，比牛郎织女的其他版本都早，因此新余被称「中国七仙女传说之乡」「七夕情人节发源地」。

更关键的一点：这个故事的学术名称是 **「天鹅处女型」（Swan Maiden）**，属于世界性母题，**遍布 50 多个国家、有 1000 多个变体**。也就是说——欧美消费者对这个原型的文化共鸣是现成的，你不需要从零解释「为什么是羽毛」。

而故事成立的三个物质条件，恰好构成一个完整的品牌叙事链：

| 传说母题 | 新余的现实基础 | 英文意象 | 可用词根 |
|---|---|---|---|
| **羽衣**（仙女所穿） | 新余自古种苎麻、织夏布，织女意象 | feather robe / plumage / pinion | `pinion` `weft` `robe` |
| **飞鸟**（仙女化为鸟） | 6000 年前遗址出土鸟形器，古越人鸟图腾；今有仙女湖白鹭 | bird / egret / heron | `heron` `avis` |
| **湖**（沐浴之处） | 仙女湖，万顷碧波 | lake / mere / linn | `lake` `linn` `fay` |

其余可用素材：**渝水**（区名由来）、**傅抱石**（国画大师，作品常署「新喻傅抱石」）、**中国洞都**（万溶洞）、**新余蜜桔**（地理标志，彭家 39 号）、**夏布**（省级非遗）。钢铁与罗坊会议属工业/红色叙事，与饰品调性不合，未采用。

## 5 短名方案：`.shop` 是个被低估的富矿

这一节是实测后**修正过的结论**。我最初以为 `.shop` 也被抢得差不多（中途有 8 个查询撞上限流，得出 35% 的错误印象），重查后真实情况是：

**`.shop` 上的四到五个字母短词，绝大多数还空着。**

| 域名 | 状态 | 域名 | 状态 |
|---|---|---|---|
| weft.shop | ✓ 可注册 | linn.shop | ✓ 可注册 |
| nest.shop | ✓ 可注册 | veil.shop | ✓ 可注册 |
| clasp.shop | ✓ 可注册 | fay.shop | ✓ 可注册 |
| knot.shop | ✓ 可注册 | yushui.shop | ✓ 可注册 |
| ochre.shop | ✓ 可注册 | baoshi.shop | ✓ 可注册 |
| grotto.shop | ✓ 可注册 | nixie.store | ✓ 可注册 |
| linn.store | ✓ 可注册 | clasp.store | ✓ 可注册 |
| knot.store | ✓ 可注册 | nest.store | ✓ 可注册 |
| grotto.store | ✓ 可注册 | yushui.store | ✓ 可注册 |
| ramie.store | ✓ 可注册 | egret.store | ✓ 可注册 |

已确认被占的只有少数：`egret.shop`、`ramie.shop`、`loom.store`。

**这意味着「简单明了」这个要求其实可以满足，只是要换后缀。** 而且 `.shop` 不是将就——它本身就是「商店」的意思，语义上和电商完美契合，比硬凑一个 `xxx.com` 更直白。

### 5.1 三种打法，按预算选

| 方案 | 做法 | 成本 | 适合 |
|---|---|---|---|
| **A 正统派** | 组合词 `.com`（如 weftvale.com） | $10/年起 | 想要最稳的域名资产，能接受名字稍长 |
| **B 简洁派** | 短词 `.shop`（如 weft.shop） | $10–30/年起，`.shop` 首年常促销 | 名字要短、要好念、要好记 |
| **C 双保险（推荐）** | 主站用 `weft.shop`，同时注册 `weftvale.com` 做品牌邮箱与跳转 | 两份钱，约 $30–40/年 | 想要短网址，又不放弃 `.com` |

**方案 C 的理由**：`.shop` 做主站，客户输入成本低；`.com` 不用于网站，但注册下来做 `hello@weftvale.com` 这种邮箱——**客户看到邮箱后缀是 `.com` 会比 `.shop` 更信任**，而且防止别人抢注你品牌的 `.com` 去做仿站。

### 5.2 关于 `.co`

**我给不出可靠结论，请不要采信任何 AI 对 `.co` 可用性的判断。** `.co`（GoDaddy Registry）不提供公共 RDAP；WHOIS 43 端口在这台机器上不通；`rdap.org` 对 `.co` 会返回假 404——连 `google.co` 都报 404，说明它不是「没注册」而是「查不到」。

要查 `.co`，只能你自己去 Namecheap 搜索框敲一下，两秒钟出结果。

## 6 你问的「品类后缀」：跟哪个词合适

你原话是「后面跟什么词合适」。这里有两层，都答：

### 6.1 品牌名后面要不要加后缀

| 后缀 | 语感 | 适用判断 |
|---|---|---|
| **Studio** | 创意工作室，最通用 | **首选**。不限定品类，从饰品到帽子到发圈全兜得住，且商标审查时「X Studio」整体判断更容易过 |
| **Collective** | 集合体 | 次选。你想强调「什么都做」时用它 |
| House（House of X） | 品牌传承感 | 想要高级感时用，但句式长 |
| Atelier | 法式工坊 | 调性最好，但美国消费者一半念不出（ah-tel-YAY），电商场景吃亏 |
| Supply / Goods | 美式实用 | 偏工装，跟波西米亚饰品不太搭 |
| & Co. | 万能 | 太常见，不加分 |

**判断规则：**

- 名字是**造词或音译**（Yushui、Nixie、Baoshi、Lakelin）→ **裸用**，不加后缀。这类名字本身够独特，加了反而累赘。
- 名字是**两个实词拼的**（Adornfield、Veilheath、Ochremoor）→ **建议加 Studio**，因为拼词的最前面那个词可能撞别人商标，加个 `Studio` 能拉开整体印象。
- 你参考的 Atolea、Pura Vida 都是裸用，因为它们是生造词。

### 6.2 品类扩展时的英文命名（导航和信息架构要用）

| 中文 | 电商通用英文 | 备注 |
|---|---|---|
| 项链 / 手链 / 戒指 / 耳环 | Necklaces / Bracelets / Rings / Earrings | 现有品类 |
| **发圈** | Hair ties 或 Scrunchies | `scrunchie` 是口语但搜索量高；`hair ties` 更正式 |
| **发夹** | Hair clips 或 Barrettes | `barrette` 是美式正式说法 |
| **帽子** | Hats / Beanies / Caps | 分细类更好卖 |
| **挂件** | Charms（配饰挂坠）/ Keychains（钥匙扣） | `charm` 在饰品语境是挂坠 |
| **统称** | **Accessories** 或 **Adornments** | 一级导航建议用 Accessories，`Adornments` 太文绉绉 |

**推荐导航结构**（既不锁死品类，又让现在的饰品占主位）：

```
Shop
├── Jewelry      ← 项链/手链/戒指/耳环/脚链
├── Hair         ← 发圈/发夹
├── Hats         ← 帽子
├── Charms       ← 挂件
└── All
```

这样将来加品类只是多一个菜单项，域名和品牌名一个字不用改——这也是为什么第 3 节那批名字全部避开「jewelry / beads」这类词。

## 7 我的推荐

推荐分两条路，取决于你更在意「名字短」还是「后缀是 .com」。

### 7.1 如果你更在意名字短好记 —— 走这条路

| 排名 | 名字 | 域名组合 | 理由 | 要做的功课 |
|---|---|---|---|---|
| **1** | **Weft** | weft.shop ＋ weftvale.com | 4 个字母、1 个音节，全球最短一档；`weft` 是织布横线，同时扣住**夏布织造**与**羽衣**（都是织出来的）；完全不含珠宝语义，明年卖帽子发圈零阻力 | `weft` 在纺织机械类可能有注册，查一次 |
| **2** | **Ochre** | ochre.shop ＋ ochremoor.com | 5 个字母，赭石色——波西米亚配大地色的标准配色，视觉延展性极强 | 色名做商标偏描述性，美国注册难度中等（可加图形元素辅助） |
| **3** | **Clasp** | clasp.shop ＋ claspgrove.com | 5 个字母，搭扣——所有佩戴物都有扣，概念上天然覆盖项链到帽子 | clasp 在五金类有使用者，查 Class 014/026 |
| **备** | **Linn** | linn.shop ＋ linnheath.com | 4 个字母，苏格兰语「湖」，仙女湖的湖 | 英国有同名地名，查英有无服饰品牌 |

> 注意：`nest.shop` 虽然可注册，但 **Nest 是 Google 旗下智能家居品牌，商标风险极高，不建议用**。

### 7.2 如果你更在意 .com 的正统感 —— 走这条路

| 排名 | 名字 | 理由 | 要做的功课 |
|---|---|---|---|
| **1** | **Pinionmere** / **Pinionlake** | `pinion` 精确对位「羽衣」（鸟翼飞羽），既不是被占烂的 plume，也不是纯描述性的 feather；mere 是古英语「湖」，双重扣住仙女湖 | 必须确认 Pinion Watches 的商标范围是否延伸到饰品 |
| **2** | **Linnheath** / **Lakelin** | `linn` 苏格兰语「湖」；发音柔软、两拍、美国人一次念对；`lakelin` 是 lake+linn 的造词，独特性更高 | 查英国有无同名服饰品牌 |
| **3** | **Baoshimoor** / **Yushuistudio** | 中文音译，海外商标几乎不可能撞车，还能讲「傅抱石」「渝水」的中国故事 | 老外不知道出处，需在 about 页讲一次 |

### 7.3 如果只让我选一个

**Weft（weft.shop + weftvale.com，方案 C 双保险）**。

三个理由：

1. **它同时满足你最在意的两件事**——短（4 字母）和好念（一个音节，美国人不会念错）
2. **它是唯一一个「织造」语义的词根**，而你真正的产品起点（不锈钢饰品 + 未来的发圈发夹）全属于「穿戴物」，织造是它们的共同母题；同时它天然接得上新余夏布的非遗叙事
3. **商标最干净**——`weft` 是纺织术语，普通消费者不知道，所以几乎没人拿它做饰品商标

代价是：老外不知道 weft 是什么意思，你需要用一句话解释（「the thread that holds the weave together」），但这恰恰是个好故事，不是负担。

## 8 商标核查：我做的是初筛，不是法律意见

我查了四个高危词（PLUME / ADORN / PINION / EGRET），用的是公开商标数据库与品牌检索。**这不等于 clearance。**

正式流程（选到 2–3 个终选后做）：

1. **免费自查**：USPTO TESS（tmsearch.uspto.gov）搜关键词 + Class 014 / 026；英国 IPO、EUIPO 各查一遍
2. **付费检索**：花 $200–400 找商标代理做 full clearance report（含普通法权利、州注册、近似图形）
3. **申请**：美国用 TEAS Plus，$250/类；先申请 Class 014（珠宝）+ 026（发饰）两个类，因为你的品类跨这两类

**为什么必须做第 2 步**：`EGRET FOREST` 那种「山东公司 2025 年注册了 Egret+自然词」的情况，免费检索很容易漏——因为你搜的是 `egretmoor`，人家注册的是 `egret forest`，字面不同但审查员会判近似。
