# 被海水打磨几十年， *它还是透光的。*

*文档编号*TG-BR-001

*版本*v2.1（字标实现修正）

*日期*2026-11-13

这份方案替代 `品牌方案-v1.0`。换名字不是审美偏好，是商标核查的结果：SEREIA 在美国已有 Class 14 珠宝类在先申请（USPTO 98755473，商品描述含耳环、手链、戒指、项链），无法安全使用。新名字必须同时满足三件事——**商标可用、域名可买、含义能承载产品事实**。TIDEGLASS 是六个候选里唯一三项全过的。

## 1 命名：为什么是 TIDEGLASS

### 1.1 字面与读音

**TIDEGLASS** = tide（潮汐）+ glass（玻璃）。两个都是英语母语者的高频词，不需要解释就能拼读。两拍重音落在 `TIDE`，念作 /ˈtaɪdɡlæs/，九个字母在字标上属于偏长但可接受的长度（参照 PATAGONIA 十个字母、TIDEWEAVE 九个字母）。

它不是生造词，也不是拉丁词根拼接——这一点很关键。DTC 饰品品牌里生造词泛滥（Atolea、Mejuri、Gorjana 都是），好处是不撞车，坏处是**没有任何语义抓手，全靠投放砸出认知**。TIDEGLASS 走的是另一条路：用两个已有的词，拼出一个视觉画面。

### 1.2 品牌故事的物理基础

**海玻璃是怎么来的：**玻璃碎片掉进海里，被浪推、被沙磨，几十年后冲上岸——棱角磨圆了，表面变成哑光，边缘半透。它被磨损得最厉害，却始终没有失去透光这件事。

这个物理事实，恰好是产品事实的同构：

| 海玻璃 | 我们的产品 | 对消费者的意义 |
| --- | --- | --- |
| 被海水与沙反复冲刷 | 316L 不锈钢 + PVD 镀层，可游泳、洗澡、睡觉佩戴 | 不需要为了首饰改变生活习惯 |
| 表面磨成哑光，但依然透光 | 镀层不掉色、不发黑、不锈 | "不褪色"不是宣传语，是材质决定的 |
| 几十年才成型 | 不追季节款，做能戴很多年的款 | 买一次，不必反复替换 |

这就是命名的核心价值：**它把"我们不掉色"这句所有竞品都会说的话，变成了一个可以被讲出来的故事。**Atolea 的 "Made for salt water" 讲的是使用场景，TIDEGLASS 讲的是时间——被磨损却不消失，比"防水"高一个层级。

### 1.3 三层含义

- **材质层**：glass 直接对应"透明感"的视觉调性——通透、半哑、有光。
- **时间层**：tide 是周期，是反复。对应"戴几年也不变"，而不是"这一季的流行款"。
- **审美层**：海玻璃是被海选过的形状，没有一个是重复的。对应我们做题材化设计（海洋 / 林地 / 星象）而不是基础款堆量。

### 1.4 六个候选的取舍

| 候选 | USPTO 珠宝类 | 域名 | 结论 |
| --- | --- | --- | --- |
| **TIDEGLASS** | ✅ 零记录 | tideglassjewelry.com / .shop / .store 可注册 | **采用**。含义、可用性、可注册性三项全过 |
| NAIADE | ✅ 无 Class 14 | naiadejewelry.com / getnaiade.com 可用 | 备选。但读音是硬伤，英语母语者念不出，口播投放会流失 |

## 2 品牌定位

### 2.1 定位声明

为 **22–38 岁、每天戴同一件首饰不想摘的北美女性**，TIDEGLASS 是**一个不用摘的饰品品牌**——因为 316L 不锈钢加 PVD 镀层让它经得起海水、淋浴与睡眠，而**终身不褪色承诺**让它敢把这件事写进政策页；不像快时尚饰品要在洗澡前摘下、三个月后换新。

### 2.2 三个支柱（按重要度排序）

| # | 支柱 | 证据（不是形容词） | 在页面上的落点 |
| --- | --- | --- | --- |
| 1 | **不褪色** | PVD 镀层 + 终身颜色保证（掉色免费换新一次，成本计入 2% 准备金） | 商品页四条卖点首位、Returns 政策页、包装卡 |
| 2 | **可碰水** | 316L 医用级不锈钢，游泳 / 淋浴 / 睡觉不摘 | 首页首屏、FAQ、佩戴场景图 |
| 3 | **低敏** | 无镍释放、无铅镉，适合敏感肌 | Materials 页、耳饰类目详情 |

顺序不能换。"低敏"是门槛项（做不到会被退货），"可碰水"是场景项（决定使用习惯），"不褪色"才是差异项——它直接对应海玻璃的故事，也是唯一能做成终身承诺的一条。

### 2.4 人群画像（一个具体的人）

**Maya，29 岁，洛杉矶，做市场策划。**她有一条款式简单的金项链，从大学戴到现在，洗澡睡觉都不摘。她不是不买首饰，而是**讨厌"要小心"的首饰**——摘来摘去、发黑、皮肤痒，都会让她干脆不戴。她愿意为"买了就不用管"多付 20–30 美元，但前提是品牌敢给承诺。她刷 TikTok 与 Instagram，买之前会翻评论里有没有人说"戴了半年还是亮的"。

这个画像推出三条设计要求：**①承诺要写在明面上**（政策页与商品页都要有，不能藏在 FAQ）；**②评论区的"用了多久"比"好不好看"更重要**（所以评价系统要收佩戴时长）；**③佩戴图必须出现水**（泳池、海边、淋浴），否则"可碰水"就只是文案。

## 3 字标与标识规范

### 3.1 字母为主，一个符号收口

v2.0 的判断是**只用字母、不做图形标**，参照 Atolea。落地到原型后发现这个判断只对了一半——问题不在"要不要符号"，而在**字距拉开之后，字标没有落点**。

v2.0 的参数是 21px / +0.18em 全大写衬线。实际渲染出来，九个字母等距排成一行，每个字母的视觉重量完全相同，看久了像**打字机打出来的编号**——这就是"生硬"的来源。修法有两条：

- **继续收紧**：字距压到 0.10em 以下，字母粘连，回到"普通单词"的观感，失去标识感。
- **拉开并加锚点**：字距放大到 0.30em 制造留白，同时在左侧放一个符号把整块视线"钉住"。**留白有了落点，才不会散。**

选了后者。但符号必须满足三条，否则还不如不加：

- **能一笔画完**——圆环 + 两道波浪，24×24 网格内可辨认，缩小到 18px 仍成形。
- **与品类有关但不成具象**——波浪指海水，圆环取海玻璃被磨圆的轮廓，不做贝壳、不做船锚（具象符号会和商品抢注意力）。
- **只能用单色**——与字标同色（Deep Sea），反白版自动跟随，不做渐变或双色。

三个用途各有一套规格：页头/页脚用「符号 + 字标」横排；favicon 与社媒头像**只用符号**（九字母在 16px 下必糊）；包装印字只印字标、不印符号（小面积印细节会脏）。

### 3.2 字标参数（v2.1 实测值）

| 项目 | 规格 | 说明 |
| --- | --- | --- |
| 字体 | **Italiana**（Google Fonts，单一字重） | 取代 v2.0 的 Cormorant / Playfair。Italiana 的大写高度更低、竖干更细、横画更薄，同字号下比二者都"轻"一档，正好抵消全大写的笨重感。系统兜底仍是 Georgia |
| 字重 | Regular 400（该字体只有一个字重） | 加粗会丢掉细笔画，且小尺寸下糊成一团 |
| 字距 | **+0.30em** | v2.0 的 0.18em 实测不足以制造呼吸感，九字母仍显拥挤。**0.30em 是本轮定稿值**：再往上字母开始各自为政，往下回到"普通单词" |
| 末位补偿 | **加 `margin-right:-0.30em`**，**不要用 text-indent** | letter-spacing 会在最后一个字母之后也留一份 0.30em，不补掉则整块字标在容器里偏左。用 text-indent 补是错的——那是把整行往右推，只会让符号和文字之间多出一道缝（本轮踩过） |
| 大小写 | 全大写 | 小写 tideglass 在字标里会显得像普通单词，失去标识感 |
| 主色 | Deep Sea `#1B3A34` | 反白版用于深色底：Cream `#FAF6EF` |
| 字号 · 桌面 | **24px** | 页头高 68px；24px 字标 + 22px 符号 + 10px 间距 ≈ 235px 宽，与 11 项导航共存不换行 |
| 字号 · 移动 | **20px / 字距降为 0.22em** | 470px 宽下 24px + 0.30em 会顶到汉堡按钮。移动端留白本就紧张，字距必须让位 |
| 符号 | 22×22px（移动 18px），与字标间距 10px（移动 8px） | 符号高度略小于字标（24px）——等高会让符号显得比字母重 |
| 最小尺寸 | 印刷 ≥ 22mm 宽；屏幕 ≥ 96px 宽 | 低于此尺寸字距需减到 0.12em，否则末字母会看不清 |
| 安全边距 | 四周 ≥ 字标高度的 1.2 倍 | 与其他元素（导航、图标）之间不得小于这个距离 |

> **为什么这轮改的是"字距"而不是"字体"。**第一反应是换一个更"艺术"的手写体（Great Vibes、Parisienne 之类）。实际比过之后放弃了：手写体在 24px 的页头高度上笔画糊成一片，手机端更糟；而且手写体与页面里的 Instrument Serif 标题不同源，整站会出现三套字形。**"艺术气息"不一定来自花体，更多来自留白节奏**——参考站 ATOLEA 也只是一个无衬线大写、字距极宽、把 A 的横杠去掉，没有一笔是花体。

### 3.3 禁用用法

- 不拉伸、不压缩、不倾斜、不加描边或投影。
- 不拆成 TIDE / GLASS 两行（拆开后读作两个词，失去品牌名的整体性）。
- 不与非品牌字体混排在同一行（如 "TIDEGLASS by xxx" 这种联名写法，首版不出现）。
- 不在花哨背景（图案、渐变、高对比照片）上直接压字标，必须先加纯色底或半透明蒙层。

### 3.4 标语（Tagline）

**Sea glass doesn't fade. Neither do we.**

中文对应：海玻璃不会褪色，我们也不会。

用法：**首页首屏第二行用斜体衬线**（与主标题形成对比），页脚与包装卡上只用第一句 `Sea glass doesn't fade.`。不要两句都放在页头——太长，会把导航挤掉。

## 5 字体系统

| 用途 | 字体 | 字号 / 字距 | 说明 |
| --- | --- | --- | --- |
| 字标 | Italiana（衬线，单一字重） | 24px / .30em 大写 · 移动 20px / .22em | 见 3.2 |
| 大标题 | 同上，斜体用于第二行 | 40–56px / -.01em | 首屏标题第二行用 italic，制造"手工感" |
| 区块标题 | 同上 | 26–28px / 0 | 不用全大写，避免与导航混淆 |
| 正文 | 无衬线（Inter / SF / 系统栈） | 14–16px / 1.75 行高 | 长段落必须无衬线，衬线在屏幕上读久会累 |
| 导航 / 按钮 / 标签 | 无衬线 | 11–12px / .14em 大写 | 全大写 + 宽字距，是这类站点建立"精致感"最省力的手段 |
| 价格 / 数字 | 无衬线，等宽数字（tabular-nums） | 同正文 | 价格列对齐靠这个；不开等宽，购物车金额会跳 |

**只允许两个字体族**：一个衬线、一个无衬线。第三个字体出现就说明设计失控了——这条比任何字号规范都管用。

## 6 摄影与图像

### 6.1 三类图，三种职责

| 类型 | 职责 | 规范 | 数量 |
| --- | --- | --- | --- |
| **产品图** | 让人看清是什么 | 正方形 1:1，浅米底（Cream 或 Sand），单一柔光源 45°，不加水印不加文字；金属表面必须有高光但不能过曝 | 每款 ≥6 张（正面 / 侧面 / 细节 / 佩戴比例 / 包装） |
| **佩戴图** | 让人知道自己戴上什么样 | **必须出现水**——泳池、海边、淋浴、洗手；肤色至少覆盖浅 / 中 / 深三档；不修掉皮肤纹理 | 每款 ≥2 张；首页与社媒主力 |
| **场景图** | 传递品牌气质 | 自然光、真实场景（沙滩石堆、木桌、旧瓷盘），不摆拍过度；色调统一压向沙与青 | 首页 3–5 张、About 页 4 张 |

### 6.2 三条禁令

- **不用纯白背景**。纯白是平台电商（Amazon）的语言，会让页面立刻"便宜"。统一用米白或沙色。
- **不加文字浮层**。图片上不放"BEST SELLER"之类的标签，标签由页面元素承担，否则图片无法在社媒与广告复用。
- **不修成塑料**。金属的划痕、珍珠的天然不均要保留——"不褪色"的说服力来自真实感，修得太干净反而像镀层很薄。

## 7 文案语气

### 7.1 三条原则

1. **先说事实，再说感受。**不写"优雅绽放你的美"，写"316L 不锈钢，游泳时不用摘"。形容词一句就够，事实要给足。
2. **句子短。**正文句长 ≤ 18 词。移动端一屏能读完一段，才有下一段。
3. **敢给承诺，也给边界。**终身颜色保证要写清"免费换新一次""人为破坏不换""运费谁承担"。敢写边界，承诺才可信。

### 7.2 句式模板

| 场景 | 模板 | 示例 |
| --- | --- | --- |
| 商品标题 | 题材 / 形态 + 品类 | Foxtrot Pendant Necklace · 单看名字就知道是一只狐狸吊坠 |
| 商品描述 | 一个画面 + 一个材质事实 | "A fox caught mid-step, cut from a single sheet of steel so the negative space draws the ear and the tail." |
| 卖点 | 四字以内的名词短语 | Lifetime Color Guarantee / Waterproof & Tarnish-Free / Hypoallergenic 316L / Free Shipping over $95 |
| 空态 | 承认现状 + 给下一步 | "Your wishlist is empty. Save the pieces you're thinking about." |
| 错误提示 | 说清原因 + 怎么改 | "That card was declined. Try another card — nothing was charged." |

### 7.3 不要这样写

| ❌ 反例 | ✅ 改法 | 原因 |
| --- | --- | --- |
| "Unleash your inner goddess" | "Swim in it. Shower in it. Sleep in it." | 空话不产生购买理由，具体场景才会 |
| "Premium quality materials" | "316L surgical stainless steel with PVD coating" | "premium" 是谁都能写的词，牌号才是证据 |
| "100% waterproof guaranteed forever" | "Waterproof. If the colour ever fades, we replace it once, free." | 绝对化承诺会招来滥用，也给不出兑现方式 |

## 8 包装与开箱

饰品的开箱是复购与晒单的起点。目标不是"豪华"，是**让人愿意拍下来**。

| 层级 | 做法 | 成本 | 要点 |
| --- | --- | --- | --- |

## 11 与 SEREIA 方案的关系

### v2.1 变更（字标实现修正）

| 项 | v2.0 | v2.1 | 为什么改 |
| --- | --- | --- | --- |
| 字体 | Cormorant / Playfair | Italiana | 同字号下更轻，抵消全大写的笨重 |
| 字距 | +0.18em | **+0.30em** | 0.18em 实测仍拥挤，九个字母像打字机 |
| 末位处理 | 等量 text-indent | 负右边距 -0.30em | text-indent 会把整行右推，造成符号与文字之间多一道缝 |
| 桌面字号 | 21px | 24px | Italiana 字面小，21px 在 68px 页头里偏弱 |
| 移动字号 | 18px | 20px / 字距 0.22em | 移动端优先保字距让位，字号可略回升 |
| 符号 | 不做 | 22px 圆环 + 双波浪，横排左侧 | 字距拉开后需要视觉落点，否则整块发飘 |

v1.0 的品牌方案在审美与语气部分仍然有效——海边质感、米白底、衬线字标、克制的文案，这些判断没有变。变的是**名字，以及名字背后的故事**。

| 维度 | SEREIA v1.0 | TIDEGLASS v2.0 | 变化原因 |
| --- | --- | --- | --- |
| 名字来源 | 葡萄牙语"美人鱼" | 海玻璃（tide + glass） | 商标冲突，必须换 |
| 故事落点 | 海妖 / 诱惑 | 被磨损但依然透光 | SEREIA 的故事是"神秘"，与"耐戴"的产品事实隔了一层；TIDEGLASS 直接同构 |
| 标语 | Made for salt water. | Sea glass doesn't fade. Neither do we. | 从场景升级到时间，且把"不褪色"写进标语 |
| 色彩 | 深青 + 米白 + 沙 | 不变 | 这套色本来就是从海边取的，与新名字更契合 |
| 字标 | 6 字母 / 23px / .24em | 9 字母 / 21px / .18em | 字母数增加，字距与字号必须重算，否则顶掉导航（已在原型修正并验证） |
| 域名 | sereia.com（被占） | tideglassjewelry.com（可注册） | — |

**一句话总结这次更换**：SEREIA 是个好听的名字，但它讲的是海的神秘；TIDEGLASS 讲的是海对东西做了什么——这恰好就是我们的产品承诺。而且这个名字没人注册。
