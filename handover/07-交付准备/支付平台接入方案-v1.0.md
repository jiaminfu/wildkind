# 支付平台接入方案 · LASTGROVE

*文档编号* LG-PAY-001　*版本* v1.0　*日期* 2026-11-15　*适用主体* 深圳市小妙摄影有限公司

> **一句话结论**：现在用 **PayPal 企业账户**（中国主体，0 成本，几天能收款）；月流水稳定超过 **$2.5–3 万** 再注册香港公司接 Stripe。
> Oceanpayment 可作为信用卡通道备选，但它有开户费 + 年费 + 10% 保证金，现在不划算。

## 1 先说硬门槛：中国主体现在开不了 Stripe 和 Airwallex 收单

这两条不是"难办"，而是**官方明确不支持**，网上大量"大陆公司可开"的教程是过时或灰色的。

### 1.1 Stripe：官方国家清单里没有中国

Stripe 官网 `stripe.com/global` 的支持清单包含 Hong Kong、Singapore、United States、United Kingdom、Japan、Malaysia、Thailand 等，**没有 China**。

官方页面在清单下方还有一句："Is your business outside of a supported country/region?" —— 这是给不支持地区用户的提示，不是开通通道。

> ⚠️ 网上流传两种"变通"：① 注册时账户地区选 Hong Kong、主体填大陆公司；② 买现成账号。
> **两种都不建议**。第①种 Stripe 要求主体注册地与经营地一致，KYC 补件时会要求香港公司证明，大概率被拒或收款后冻结；第②种账号所有权不在你手上，随时归零，而且资金被冻结时无法申诉。

### 1.2 Airwallex：收单功能仅限非中国主体

Airwallex 中文官网定价页的脚注原文：

> **7. 以下服务仅针对非中国主体的客户适用。**（第 7 条对应「全球收单」表格）
> 注：本页面信息不构成对中国大陆地区的推广或要约

也就是说：

| 功能 | 中国主体 | 香港/海外主体 |
|---|---|---|
| 全球企业账户（收款、换汇、付款） | ✅ 可开 | ✅ |
| **全球收单（在线卡支付）** | ❌ **不可** | ✅ |
| 企业卡 | ❌ | ✅ |

我上一轮给你提的"Airwallex 主收单 + PayPal 兜底"**这条是错的**，当时没查到底层资质要求。以本节为准。

## 2 中国主体真正能用的收单通道

面向美加英的实物饰品独立站，现在可选的只有三类：

| 平台 | 主体要求 | 卡费率（签约口径） | 固定成本 | 保证金 | 结算 | 开户周期 |
|---|---|---|---|---|---|---|
| **PayPal 企业账户** | 大陆营业执照即可 | **4.40% + $0.30** | 无 | 视风控，可能有准备金 | T+3～7，可提现人民币 | 2–5 工作日 |
| **Oceanpayment 钱海** | 大陆营业执照 | 3.3% + $0.30（常见）<br>区间 2.9%–3.9% | 开户费 + 年费<br>（市场口径 5,000 元 / 5,000 元） | 10%，180 天 | T+7～10 | 1–3 周 |
| **Asiabill / UseePay 等** | 大陆营业执照 | 需询价 | 需询价 | 需询价 | 需询价 | 1–3 周 |

> 表中费率来自公开资料，**各家按类目、卡种、月流水单独报价**，签约前必须以对方书面报价为准。
> Oceanpayment 的"开户费"口径在各来源不一致（有说免开户费的），我不替你判断，你询价时直接问"首年总成本是多少"。

### 2.1 PayPal 中国区的真实费率

很多文章写"2.9%+$0.3"，那是**美国本土商户**费率。中国大陆账户收海外买家：

| 项目 | 费率 |
|---|---|
| 收国际交易（卡 / PayPal 余额） | **4.40% + 固定费**（美元 $0.30） |
| 提现 — 跨境收款结汇人民币 | 标准 1.0%，2026-01-15～12-31 优惠 **0.5% 封顶**（仅美元余额） |
| 提现 — 美元电汇到大陆银行 | $35 / 笔 |
| 换汇加点 | 约 2.5%（隐含在汇率里） |
| 争议处理费（大陆账户） | $8 / 笔 |

**你的客单价场景**（按 AOV $55 估算）：

- PayPal：55 × 4.40% + 0.30 = **$2.72**（占 4.95%）
- Oceanpayment（3.3%）：55 × 3.3% + 0.30 = **$2.12**（占 3.85%）
- Stripe US（2.9%）：55 × 2.9% + 0.30 = **$1.90**（占 3.45%）

单笔差 $0.2–0.8。**客单价越低，固定费 $0.30 占比越高**——你 $35 的脚链，PayPal 手续费占比接近 5.3%。

## 3 算账：什么时候才值得注册香港公司

香港公司不是"注册完就省钱"，它有固定维护成本。

### 3.1 成本（2026 年市场行情）

| 项目 | 首年 | 每年续 |
|---|---|---|
| 政府规费（注册费 + 商业登记证） | 约 3,900–4,000 港元 | 商业登记证约 2,150 港元 |
| 法定秘书 + 注册地址 | 3,000–5,000 港元 | 同 |
| 代理服务费 | 2,500–4,800 元人民币 | — |
| 银行开户（如需协助） | 4,500–6,800 元人民币 | 账户管理费 600–1,200 港元 |
| 审计（持牌会计师，必做） | — | 3,000–8,000 港元 |
| **合计** | **约 1.2–1.8 万人民币** | **约 0.8–1.5 万港元** |

开户还有个门槛：汇丰、中银香港通常要 **5 万港元起存**；ZA Bank 等数字银行无最低存款，但审业务真实性。

### 3.2 盈亏平衡点

Stripe（香港主体）费率按 3.4% 估，对比 PayPal 4.40%：

| 月流水 | PayPal 年成本 | Stripe 年成本 | 年差额 | 是否覆盖香港公司维护费（约 1.2 万人民币 ≈ $1,650） |
|---|---|---|---|---|
| $5,000 | $2,640 | $2,040 | $600 | ❌ 不够 |
| $10,000 | $5,280 | $4,080 | $1,200 | ❌ 差一点 |
| **$25,000** | $13,200 | $10,200 | **$3,000** | ✅ 够，且有余 |
| $50,000 | $26,400 | $20,400 | $6,000 | ✅ 明显划算 |

**结论：月流水稳定在 $2.5 万以上（约 450 单/月），香港公司才开始正收益。** 在此之前，多付的 PayPal 手续费比公司维护费便宜。

### 3.3 美国 LLC 这条路我不建议你走

Stripe Atlas 是 $500 一次性，看起来比香港便宜。但：

- 需要做 **BOI 受益所有人申报**（FinCEN 严查，不报或错报 LLC 会被强制解散）
- 需要每年报 **Form 5472 + 1120**，**漏报罚款 $25,000 起**，没有美国会计师几乎不可能自己搞定
- 特拉华州每年 franchise tax，怀俄明每年年报费
- 美国来源收入要缴税，且中美税收协定对 LLC 的适用有争议

单人运营、没有美国会计师的情况下，**这个 $25,000 的罚款风险不值得为 0.5% 的费率去承担**。

## 4 推荐路线

### 阶段 1 · 现在（本周就能收钱）

**开 PayPal 企业账户**，用大陆公司主体。

- 成本：0
- 时间：2–5 个工作日审核
- 能收：Visa / Mastercard / Amex / PayPal 余额（买家不需要有 PayPal 账号也能用卡付）
- 覆盖：美加英全覆盖，且欧美用户对 PayPal 有天然信任

**同时准备好信用卡通道的后备方案**：向 Oceanpayment 询一次价，拿到书面报价放着。不要现在签——开户费 + 保证金对小流水不划算，但**询价不花钱**，而且知道真实报价后你能判断什么时候该切。

### 阶段 2 · 月流水过 $1 万

做两件事：

1. **补 Oceanpayment 或 Asiabill 作为第二通道**，把信用卡支付从 PayPal 分流出去（PayPal 只留钱包支付的用户）
2. 开始准备香港公司材料（不用马上注册）

两条通道并行不是为了省钱，是**防单点故障**——任何一条通道都可能因为拒付率、银行政策变化被冻，只有一条的时候你会直接断收入。

### 阶段 3 · 月流水稳定过 $2.5 万

**注册香港公司 + 开 Stripe + Airwallex**

- 香港公司接 Stripe（费率约 3.4%，风控比大陆主体宽松得多）
- 香港公司接 Airwallex 收单（可做多币种、本地支付方式）
- PayPal 降为辅助通道
- 资金路径：Stripe/Airwallex → 香港银行账户 → 结汇回内地

**注意**：香港公司要和内地公司形成合规贸易关系（内地采购主体 + 香港销售主体），不能只是"收钱的壳"，否则审计和离岸豁免申请都会出问题。

## 7 我这边要做的技术接入（你拿到账号后）

代码里的支付抽象层已经写好了（`app/server/lib/payments/`），四个通道都在：`mock` / `stripe` / `airwallex` / `paypal`。

你开好 PayPal 后，我只需要：

1. 填 `PAYMENT_PROVIDER=paypal` 和三个密钥（Client ID / Secret / Webhook ID）
2. 前端挂 PayPal JS SDK（现在留了 TODO）
3. 验证 webhook 验签（用原始字节，代码已实现）
4. 跑一笔真卡小额单，确认「下单 → 付款 → 回调 → 订单状态变 paid → 邮件发出」全链路
5. 把 `PAYMENT_PROVIDER` 从 `mock` 切走——**现在线上还是 mock，会标记已支付但不实际收款，不能对外营业**

前置条件：**Resend 邮件必须配好**，否则客户付了钱收不到确认信，这是 PayPal 审核也会看的项。

## 8 风险与注意事项

| 风险 | 说明 | 应对 |
|---|---|---|
| **PayPal 冻结** | 新账户突然放量最容易触发，被冻时资金可扣留 180 天 | 第一个月单笔不超过 $200、月流水不超过 $5,000，逐步放量；发货必须用**真实可追踪单号** |
| **拒付率红线** | PayPal 争议率超 1% 会限提现，超限可能关户 | 饰品常见拒付原因是"没收到"和"与描述不符"，做好物流追踪 + 实拍图 |
| **准备金** | PayPal 可能扣留部分余额 180 天 | 现金流要留出这部分，别把回款算满 |
| **网站审核不通过** | 无 HTTPS、无政策页、商品太少、联系方式缺失 | 我们已有 12 个政策页 + 37 商品，只差 DNS |
| **类目不符** | 经营范围与售卖品类不一致 | 先做工商变更 |
| **单通道断流** | 任何通道都可能因政策变化停摆 | 阶段 2 起必须双通道 |
